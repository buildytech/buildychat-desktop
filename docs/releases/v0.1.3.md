BuildY Chat desktop 0.1.3, with the web app from `buildytech/chat` at `83c4a18`.

- **Switching skins reaches every block.** Switching between custom skins left the simple blocks of the side catalog on the old colours, or took the new ones only sometimes. The catalog cards re-read the skin only when the registry skin under it changed, and two custom skins usually share one; and slow style loads could finish out of order. The preview, the catalog cards, the preview window and the ZIP now take the skin from one place and one writer: the last skin chosen always wins, it is applied in one step, in light and dark, and again whenever the preview frame reloads.
- **One list of skins.** A skin made by Design and a theme imported in Settings are the same record in the same Project Skin list. An import is selected right away, importing a different theme again is the next revision of that skin, and Design can edit it like its own. **Export** in Settings now gives the chosen skin, whichever way it was made.
- **Theme files of the Stock theme editor (codegen-x/ui8kit) import as a regular skin and export back unchanged.** Its Export (format `magazine-theme` v2) and also the older shapes its own reader takes: the stored `{ v: 1, theme }`, a bare theme and a style preset. A value that would be lost is named in the import message instead of being dropped silently.
