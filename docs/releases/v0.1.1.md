BuildY Chat desktop 0.1.1, with the web app from `buildytech/chat` at `aa87fd5`.

- **Design uses the same provider and model as the other roles.** Settings has a fourth row, Design, which defaults to "Same as Build" (provider, model, state, spend). `POST /runtime/v1/design` takes that role's provider and the app's model id.
- **OpenRouter Design works with Grok 4.20 Non-reasoning.** 0.1.0 sent the app id `grok-4.20-0309-non-reasoning` on the OpenRouter wire and the host answered `model_not_listed` (the UI then showed only "The design request could not be completed."). The host now maps that id to `x-ai/grok-4.20` with `reasoning: { enabled: false }`, the same mapping as the catalog loop, and surfaces the host's code and message when a request fails.
- **Ask cannot apply a change.** The Ask prompt forbids claiming that a page or theme was applied. If an answer still says it was, the thread shows "Nothing was changed" and, when the text is a style brief, **Apply in Design** — that switches to Design and sends the answer as a brief; Design validates and, if it accepts, writes a Brand Skin. Ask itself writes nothing.
