First published release of the BuildY Chat desktop app (unsigned builds). The app is the BuildY web app from
`buildytech/chat` at `e250e95`, with the runtime in the app itself.

- **Design mode.** The fourth composer mode next to Ask, Build and Media: the agent writes a brand brief and a theme,
  the app validates it (fonts, radius, WCAG AA contrast) and keeps it as a per-project Brand Skin. The Project Skin
  selector lists the default theme, the Brand Skins of the project and the kit skins. The desktop host answers
  `POST /runtime/v1/design` on the provider the app is signed in with (xAI key or OpenRouter), under the owner's
  approved-model lists.
- **Go templ export.** "Download ZIP" can write a Go templ site on `fastygo/starter` (blog, corporate or shop preset)
  next to the Svelte site; both wear the project's skin.
- **Windows files carry `.exe`.** The installer, the portable ZIP (`buildychat.exe`) and the raw CI binaries
  (`buildychat.exe`, `buildychat-server.exe`).
- **Releases.** A `v*` tag builds the installers and publishes them here with `SHA256SUMS`.

Unsigned: Windows SmartScreen and macOS Gatekeeper warn on first start. Run the Windows portable ZIP after unzipping;
set the key with `buildychat.exe --set-key` or in Settings.
